## 1. 范围与背景

以**套件**圈定用例运行范围（目录 + 标签配置），降低仅依赖模块 + 标签组合的心智成本；支持列表维护、查询与删除。

---

## 2. 用户与场景

- 测试开发将某版本下「某目录树 + 标签」固化为套件，在新建运行任务时一键选用。

---

## 3. 功能需求（按二级需求）

### 3.1 新建套件（REQ-011）

- 字段：套件名称、用例范围（目录+标签配置）、套件说明。  
- **套件名称唯一**；重复时界面提示已存在。

### 3.2 套件列表（REQ-012）

- 列：套件名称、用例范围、套件说明、创建时间、创建人；操作：编辑、删除。

### 3.3 编辑套件（REQ-013）

- 弹框可编辑：套件名称、用例范围、套件说明。

### 3.4 套件查询（REQ-014）

- 支持按套件名称等条件检索（**清单注明细则待补全**，筛选项与 UI PRD 对齐）。

### 3.5 删除套件（REQ-015）

- 删除前确认：「确认删除XXX套件？」
