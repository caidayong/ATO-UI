## 1. 范围与背景

在用例管理目录上下文中，增强**目录与分组绑定**、**批量复制与批量打标签**能力，并优化**单用例调试结果**可读性，支撑并行协作与运维效率。

**非目标**：用例步骤编辑器内核重构、非本迭代引入的执行引擎协议变更。

---

## 2. 用户与场景

- 维护者需在目录级绑定**唯一分组**，支撑后续并行运行编排。  
- 跨目录复用用例时通过**复制到**减少手工搬迁。  
- 批量迁移后通过**新增标签**快速打标。  
- 调试时一眼看到**失败步骤**与**总结果**。

---

## 3. 功能需求（按二级需求）

### 3.1 模块标签、分组（REQ-002、003）

- 进入目录/子目录后展示 **「标签/分组」** Tab（或等价分区）。  
- **添加分组**：分组下拉选择；**同一目录仅可选一个分组**；分组**非必填**；可**删除分组**并解除绑定。  
- **删除模块分组**：与 Tab、下拉、删除按钮联动，删除后绑定关系解除（细则与交互 PRD 对齐）。

### 3.2 测试用例编辑 — 批量复制到（REQ-004）

- 列表多选 → **复制到** → 弹框选择目标目录 → 确认。  
- 目标目录已存在**同名用例**：提示「XXX目录下已存在相同用例，请确认」，**复制失败**。

### 3.3 测试用例编辑 — 批量添加标签（REQ-005）

- 列表多选 → **新增标签** → 弹框选择标签 → 确认。  
- 若用例已有**同名标签**则**覆盖**。

### 3.4 用例调试运行 — 结果显示优化（REQ-006）

- 单用例运行结束，调试详情抽屉展示**总结果**：成功 / 失败 / 跳过。  
- 步骤列表**最左侧**展示步骤结果（成功 ✅ 绿色、失败 ❌ 红色）。

## 4. 清单逐行追溯

| 需求 ID | 类型 | 优先级 | 是否涉及 UI | 二级需求 | 三级需求 | 验收要点 |
|---------|------|--------|-------------|----------|----------|----------|

| REQ-005 | 新增 | 中 | 是 | 测试用例编辑 | 用例批量添加标签 | 覆盖策略正确；批量反馈完整 |
| REQ-006 | 优化 | 中 | 是 | 用例调试运行 | 单用例运行调试-结果显示优化 | 总结果与步骤标识与后端一致 |

---

## 5. 非功能与约束

- 批量操作需有**进度或结果摘要**（全部成功/部分失败列表明细，细则待 UI）。  
- 权限：无编辑权限时批量入口隐藏或禁用并提示。

---

## 6. 异常与边界

| 场景 | 行为 |
|------|------|
| 未多选即点批量按钮 | 禁用或 Toast 提示 |
| 目标目录无权限 | 禁止复制并提示 |
| 调试结果部分步骤无状态 | 展示占位或「未执行」（待产品） |

---

## 7. 影响范围与依赖

- **分组管理**：目录可选分组数据来源于分组主数据，见 `ATO-V1.0.1-P5-分组管理_需求文档.md`。  
- **测试运行**：并行编排依赖目录分组绑定，见 `ATO-V1.0.1-P5-测试运行_需求文档.md`。
