- **不在**主框架列表内容区增加全宽页面副标题（与 `ProductionPlanList` 等一致）；导航语义由顶栏面包屑承担。

### 1.4 状态枚举与颜色映射

### 1.5 通用交互规范

- **删除（套件）**：确认文案必须为 **「确认删除{套件名称}套件？」**；确认后删除。
- **删除（Tab2 分析报告任务）**：任务状态为 **「进行中」** 时 **不允许删除**——操作列「删除」**`disabled`**，**`Tooltip`** **「进行中不可删除」**（或等价短句）。**非进行中**（**已完成**、**异常**）允许删除：点击后 **`Modal.confirm`**，推荐文案 **「此操作不可恢复，是否继续？」**，可取消。
- **Tab2 操作列 · 重新生成 / 发送邮件（与 `MarketDefectAnalysisTasksTab.tsx` 对齐）**  
  - **进行中**：**重新生成**、**发送邮件**、**删除** 均为 **`disabled`**；`Tooltip` 分别为「进行中不可重新生成」「进行中不可发送邮件」「进行中不可删除」。  
  - **已完成** 或 **异常**：**重新生成** 可点，点击后该行 **任务状态** 更新为 **「进行中」**（Mock Toast 提示）。  
  - **异常**：**发送邮件** **`disabled`**，`Tooltip` **「异常状态不可发送邮件」**；**已完成** 时 **发送邮件** 可用。  
- **发送邮件（REQ-036，Tab2 + 报告详情共用 `MarketDefectSendMailModal`）**  
  - **`Modal`**：**发件人** 只读单行（Mock：`张三 <zhangsan@company.com>`）；**收件人** — `Select` **`mode="multiple"`** + **`showSearch`**，选项来自 **`mockUsers`**，展示 `姓名 <邮箱>`，占位 **「支持按姓名/邮箱模糊搜索，支持多选」**，支持姓名 / 邮箱 / 工号模糊过滤；**团队选择** — 单行 `Select`，选项 **`mockTeams.name`**，占位 **「单选团队」**；两字段同一行栅格约 **18:6**（大屏），小屏纵向堆叠。  
  - **默认值**：打开时若当前报告 **归属团队** 存在于 `mockTeams`，则 **团队选择** 预填该值。  
  - **按钮**：**确认发送** / **取消**；首版 **Toast** 模拟成功（无真实发信）。  
- **其它危险操作**（本迭代未单独约定的）：二次确认推荐 **「此操作不可恢复，是否继续？」**，可取消。
- **搜索框**：支持 **Enter** 触发查询；筛选默认含「全部」选项。
- **空态**：列表无数据时 `Empty` + 引导主操作（如「去新建套件」「创建缺陷分析报告」）。
- **占位卡片**：整卡点击 → `message.info`（或等价）**「待规划，敬请期待」**。
- **权限（本迭代）**：**不**按角色隐藏或禁用写操作、导出、邮件、报告详情「编辑」；**编辑**是否可用仍受 **任务状态** 与 **迭代需求清单** 约束。

## 2 数据流与状态机（本迭代）

### 2.1 数据获取与 Mock 边界

| 页面 / 模块 | 时机 | 说明 |
|-------------|------|------|
| 套件管理 | 进入页面 | **Mock**：`GET` 等价本地 `mockSuites`；后续对接版本维度 API |
| 市场缺陷列表 | Tab 激活 / 筛选变更 / 全局刷新 / 行刷新 | **Mock** 列表 + 同步接口占位；RDMS 详情 **`Modal` 首版仅 Mock HTML 结构**（对齐 REQ-028），**不**嵌入真实 RDMS **`iframe`** / 外域生产 URL |
| 市场缺陷分析 Tab2 | Tab 激活 / 搜索 | **Mock** 分析任务列表 |
| 报表页 | 进入 / 生成报表 | 读取「列表页传入状态」：默认 **`sessionStorage` 快照**（键名与序列化格式见 **§7.1 第 4 条**）；图表区 **首版纯 UI 占位**（见 §3.4），**不**接入 `@ant-design/charts` |
| 报告详情 | 进入 / 保存 | **Mock** 单条任务 + 保存成功 Toast |

**原则**：所有远端能力以 **占位 + 可切换 Mock** 实现；不在 PRD 中虚构真实后端路径，工程实现时由接口契约单独文档化。

### 2.2 跨页状态（报表数据集）

- **输入**：市场缺陷列表当前 **时间条件（年 / 季度 / 月，按「创建日期」解析）+ 表头列筛选（是否有效问题、实际归属团队、主要责任归属）+ 单一搜索框（REQ-029 语义：多字段子串匹配）** 所确定的 **当前列表结果集**（与 Tab1 `filtered` 一致）。
- **传递（前端默认）**：跳转报表前将上述条件 + 搜索文案 + 分页元数据 **序列化写入 `sessionStorage` 固定键**；报表页进入时读取；详见 **§7.1 第 4 条**。报表页右侧「注」固定说明数据来源于列表检索。
- **输出**：生成报表仅影响本页右侧展示区，不回写列表。

### 2.3 报告详情：只读 / 编辑（工程口径 **2026-05-11**）

   ↑                         |
