## 1. 范围与背景

提供用例**分组主数据**的增删改查，支撑目录绑定与测试运行**并行编排**；引导先定义分组再绑定目录，降低多人并行维护混乱。

---

## 2. 用户与场景

- **作为**模块 Owner，**需要**创建与维护业务分组，**以便**运行任务按分组编排、目录侧可引用。

---

## 3. 功能需求（按二级需求）

### 3.1 添加分组（REQ-007）

- 弹框：**组名（必填）**、**分组说明**；保存后写入列表。

### 3.2 分组列表（REQ-008）

- 列：组名、分组说明、创建时间；操作：编辑、删除。

### 3.3 分组编辑（REQ-009）

- 列表 **编辑** → 弹框修改分组信息 → 保存。

### 3.4 删除分组（REQ-010）

- 列表 **删除** → 确认文案「确认删除XXXX」→ 执行删除。

---

## 4. 清单逐行追溯

| 需求 ID | 类型 | 优先级 | 是否涉及 UI | 二级需求 | 验收要点 |
|---------|------|--------|-------------|----------|----------|

---

## 5. 非功能与约束

- 删除分组时若仍有目录绑定：**建议阻断删除并提示先解绑**（推断，待产品确认清单未写细则）。

---

## 6. 异常与边界

| 场景 | 行为 |
|------|------|
| 组名重复 | 服务端/前端规则二选一，须明确提示 |
| 删除被引用分组 | 见 §5 |

---
