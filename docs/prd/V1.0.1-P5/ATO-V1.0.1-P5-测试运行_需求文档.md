## 1. 范围与背景

在新建/配置运行任务时支持**模块与分组的串并行编排**、**套件作为范围与模块/标签的与关系**，并在**测试报告总览**展示目录级耗时，缩短调试周期、便于识别慢模块。

**非目标**：执行器底层调度引擎替换、跨版本历史报告迁移。

---

## 2. 用户与场景

- 多模块版本希望**分组并行 + 模块串行**组合执行。  
- 希望直接选**测试套件**缩小范围。  
- 报告阶段对比各**目录耗时（min）**以优化用例分布。

---

## 3. 功能需求（按二级需求）

### 3.1 运行配置 — 用例并行配置（REQ-016）

- **前置**：模块解耦或分组已配置（与用例管理/分组管理联动）。  
- 新建任务支持 **模块模式 / 分组模式** 与 **串并行编排**；**按编排顺序执行**。  
- **未纳入编排的模块/分组不执行**。  
- **分组模式**下：**未分组模块默认最后串行**。

### 3.2 运行配置 — 范围配置支持套件选择（REQ-017）

- 范围配置增加 **测试套件** 下拉（**单选**）。  
- 与 **模块**、**标签** 筛选为 **与（AND）** 关系。  
- 若所选 **模块** 与 **套件范围** **冲突** → 提示 **无法创建任务并运行**（阻断）。

### 3.3 测试报告 — 目录级耗时（REQ-018）

- **前置**：用例已跑完。  
- 报告总览左侧目录树：每一目录行 **最右侧** 展示该目录运行耗时，单位 **min**。

## 4. 清单逐行追溯

| 需求 ID | 类型 | 优先级 | 是否涉及 UI | 二级需求 | 三级需求 | 验收要点 |
|---------|------|--------|-------------|----------|----------|----------|
| REQ-016 | 新增 | 高 | 是 | 运行配置 | 用例并行配置 | 编排顺序与执行一致；未编排不执行；未分组最后串行 |
| REQ-017 | 新增 | 低 | 是 | 运行配置 | 范围配置支持套件选择 | 与模块/标签 AND；冲突阻断 |
| REQ-018 | 新增 | 高 | 是 | 测试报告 | 测试报告总览支持模块级耗时统计与展示 | 仅跑完后展示；单位 min；与统计口径一致 |

---

## 5. 非功能与约束

- 编排配置须**可保存、可回显、可校验**；非法配置在创建任务前拦截。

---

## 6. 异常与边界

| 场景 | 行为 |
|------|------|
| 前置未满足（无分组数据等） | 禁用并行模式或引导去配置 |
| 报告未完成 | 目录树不展示或展示「—」（待产品） |
| 耗时聚合与并行重叠 | 以后端口径为准，前端不二次错误聚合 |

---

## 7. 影响范围与依赖

- **用例管理 / 分组管理 / 套件管理**：编排与范围的数据源，互链见对应 PRD。  
- **平台自动化 · 任务配置**：并行与套件规则须 **与 REQ-016/017 对齐**，见 `ATO-V1.0.1-P5-任务配置_需求文档.md`。
