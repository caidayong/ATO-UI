## 1. 范围与背景

使 **平台自动化** 侧任务配置在 **并行编排** 与 **套件范围** 上与 **版本用例开发 · 测试运行** 规则一致，降低双端心智与配置错误。

---

## 2. 用户与场景

- 开发在平台自动化创建任务时，复用与版本侧相同的并行与套件语义，避免「一端能跑一端不能」。

---

## 3. 功能需求

### 3.1 用例运行配置支持并行配置（REQ-020）

- **前置、编排、异常处理规则** 与版本用例侧 **「用例并行配置」**（REQ-016）一致：模块/分组、串并行、未编排不执行、未分组最后串行等。

### 3.2 用例运行配置支持套件选择（REQ-021）

- 范围配置增加 **测试套件** 下拉（单选）；与模块、标签为 **与**。  
- 模块与套件范围 **冲突** 时提示 **无法创建并运行**（与 REQ-017 对齐）。

---

## 4. 清单逐行追溯

| 需求 ID | 类型 | 优先级 | 是否涉及 UI | 二级需求 | 验收要点 |

| REQ-021 | 新增 | 中 | 是 | 用例运行配置支持套件选择 | 与 REQ-017 行为对照验收 |

## 5. 非功能与约束

---

## 6. 异常与边界

同 **测试运行** 文档中与并行、套件相关的边界；不一致视为缺陷。
