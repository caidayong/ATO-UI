# ATO V1.0.1-P4 履历表管理（新增）

> **类型**：新增  
> **对齐基线**：`ATO_V1.0.1-P4-页面需求与交互规格.md`（4.3） + `src/pages/ResumeManagement.tsx`

---

## 1. 需求范围

- REQ-V1.0.1-P4-011 ~ REQ-V1.0.1-P4-015
- 覆盖页面：`/ptsw/resume`

## 2. 功能需求清单（按功能维度）

### 2.1 履历列表

- **功能目标**：展示履历数据并提供维护操作入口。
- **操作栏**：`新增板卡`、`批量替换`、关键字查询。
- **列表字段（顺序固定）**：
  - 序号、板卡料号、物料描述、IC料号、IC型号、软件版本、Checksum值、软件状态、存放路径、发布人、备注、操作（编辑/删除）
- **UI交互**：
  - 列表按“一个板卡一行”聚合；
  - 同板卡多组 IC 在单行内分行展示，组间分隔线区分；
  - 支持行勾选，作为批量替换目标范围。
- **限制与异常**：
  - 查询无结果显示空表态，不影响后续新增/批量替换入口可见性。

### 2.2 新增板卡

- **功能目标**：新增板卡履历及其多组 IC 软件信息。
- **交互入口**：操作栏 `新增板卡` 按钮。
- **弹窗结构**：
  - 板卡信息区：板卡料号、物料描述
  - IC信息区：支持动态增删多组 IC 信息
- **IC字段**：
  - IC料号、IC型号、软件版本、软件状态、存放路径、发布人、备注
- **软件状态枚举**：`正常`、`已下架`、`试产`。
- **限制与异常**：
  - 物料描述必填；
  - 至少保留 1 组 IC 信息；
  - 新增成功后返回列表并提示成功。

### 2.3 编辑板卡

- **功能目标**：修改既有板卡履历与 IC 软件信息。
- **交互入口**：列表操作列 `编辑`。
- **编辑行为**：
  - 弹窗结构与新增一致；
  - 支持对现有多组 IC 信息增删改；
  - 保存后实时回写列表展示。
- **限制与异常**：
  - 校验规则与新增一致（物料描述必填、IC组至少1条）。

### 2.4 删除板卡

- **功能目标**：删除板卡履历数据。
- **交互入口**：列表操作列 `删除`。
- **确认机制**：
  - 二次确认文案固定：`此操作不可恢复，是否继续？`
- **执行结果**：
  - 删除目标板卡时，同组 IC 信息一并删除。
- **限制与异常**：
  - 删除成功后列表即时移除并提示成功。

### 2.5 批量替换

- **功能目标**：按板卡范围批量替换软件信息。
- **交互入口**：操作栏 `批量替换`。
- **功能范围（本期限定）**：
  - 仅支持三字段替换：软件版本、Checksum值、存放路径。
- **交互流程**：
  - 先勾选目标板卡；
  - 查找区输入“查找内容-软件版本”后自动回填“查找内容-Checksum值/存放路径”；
  - 输入“替换为-软件版本/Checksum值/存放路径”并确认提交。
- **限制与异常**：
  - 未勾选记录时阻断并提示“请先勾选要批量替换的记录”；
  - 查找或替换必填项缺失时阻断提交并提示。

### 2.6 查询筛选

- **功能目标**：快速定位板卡或 IC 软件记录。
- **查询范围**：
  - 支持板卡料号、物料描述、IC料号、IC型号、软件版本、软件状态、发布人、存放路径、备注等关键词检索。
- **UI交互**：
  - 输入即过滤当前列表；
  - 查询后自动回到第一页。
- **限制与异常**：
  - 仅前端过滤，不改变底层数据；
  - 清空关键字后恢复全量展示。

## 3. 数据规则与一致性说明

- Checksum值与软件版本一一对应：有软件版本即应有对应 Checksum值（字段名可沿用 `checksumMd5`）。
- 未显式填写 Checksum值时，系统可按规则自动生成。
- 软件状态枚举固定为：`正常`、`已下架`、`试产`。

## 4. 验收口径

- 六类功能（履历列表/新增板卡/编辑板卡/删除板卡/批量替换/查询筛选）均有完整的目标、交互、限制和异常描述。
- 字段命名、交互行为、校验规则与当前页面实现保持一致。
