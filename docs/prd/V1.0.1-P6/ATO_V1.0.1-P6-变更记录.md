## 3 项目日报 Tab（REQ-010～016）

| 变更项 | 定稿 PRD | 验收实现 | 原因 |
|--------|----------|----------|------|
| 工具栏布局 | 右上「新建」 | **左侧**「新建日报」+「团队」筛选 | 验收稿信息架构 |
| 列表列 | 无「所属团队」 | 增 **所属团队**；创建时间 **仅日期** | 多团队运维 |
| 操作列 | 文字链接：编辑/启停/删除/手动发送 | **图标** + Tooltip：编辑、**生成/停止**、删除、发送邮件；行末 Loading/✅ | 操作密度与生成态可见 |
| 定时启停 | 列表「启动/停止」控制定时邮件 | **移除**；改为「生成/停止」报告生成 Mock | 产品口径调整 |
| 项目状态枚举 | 正常/已发布/延期/暂停 | **正常/已完成/延期/暂停** | 与业务「版本完成」语义一致 |
| 删除规则 | 已发布/暂停可删 | **已完成/暂停**可删 | 随状态枚举更名 |
| 新建弹窗 | 4 阶段测试计划含「版本发布」 | **3 阶段**（冒烟/SIT/UAT）；新建时各阶段起止 **必填**；增 **所属团队*** | 验收简化 |
| 新建弹窗 | 含项目状态 | **不含**项目状态（编辑时可改） | 新建默认正常 |
| 邮件模式 | 定时/手动/定时+手动 | **仅** 手动 / 定时；定时含生效日期+每日时刻 | 验收简化 |
| 邮件收件 | 固定邮件组 | `senders[]` 多发送人 | 验收稿 |
| DEV 角色切换 | 建议 dev 顶栏 Select | **移除**；权限取自基础数据当前用户 Mock 角色 | 贴近真实权限 |

## 5 项目周报 Tab（REQ-017～020、023、025）

| 变更项 | 定稿 PRD | 验收实现 | 原因 |
|--------|----------|----------|------|
| 团队下拉 | 含「全部」只读汇总 | **无「全部」**；前缀文案「团队」 | 验收稿 |
| 周切换 | 「上周」「本周」两按钮 | **相对周偏移**：默认本周仅「上周」；历史周显示「上周」「下周」「本周」 | 可浏览任意历史周 |
| 历史周 | 上周只读 | 历史自然周 Mock **已提交**只读；**草稿**可编辑（与状态联动） | 与数据态一致 |
| 产品列 | RDMS Select | **自定义文本** Input | P6 Mock 简化 |
| 测试人员 | 单选 UserSelect | **多选**下拉 | 验收稿 |
| 统计/设置入口 | 文字按钮 + 角色显隐 | 右上角 **图标**常显；仍按 lead/admin 控制可用性 | 视觉收敛 |
| 设置 Modal | 检测时刻 + 汇总星期时刻 + 邮件组 | 团队/负责人/**钉钉号**列表（团队不可重复）；检测/发送均为 **每周星期几 + HH:mm:ss** | 验收稿 |
