| 业务模块 | 是 | 与 `.cursor/rules/requirements-module-split.mdc` 中「业务模块」列一致 |

| 三级需求 | 否 | 子场景、关键步骤、验收要点等 |
| 需求说明 | 否（**强烈推荐**） | 业务口径、规则、枚举、边界；须达 **可验收** 粒度（见 §8） |
| 需求动机 | 是 | 为什么要做（问题、价值、目标） |

| 是否已实现 | 是 | 是 / 否 / 部分实现 |
| 关联页面/入口 | 否（**有 UI 时推荐**） | 菜单路径或 **路由**（与 §2.1 一致） |
| 备注 | 否 | 主从关系、附录引用等 |
