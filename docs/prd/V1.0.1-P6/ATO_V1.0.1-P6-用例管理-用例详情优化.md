## 0 变更摘要

| 项 | 原状 | 新状 |
|----|------|------|
| 步骤导航 | 左侧竖向列表 + 右侧详情（可拖拽分栏） | **上方横向 Tab** + **下方详情** |
| 步骤操作 | 行内 ⋯、底部批量复制按钮、Checkbox 多选 | **右键 / Tab ⋯** 单步菜单；**复制当前步骤** 追加剪贴板 |
| If/For | 嵌套在左侧步骤列表 | **Tab 占一格**；分支与子步骤在 **下方上下分块** |
| 单用例调试结果 | 右侧抽屉覆盖详情区 | **底部抽屉**；内为 **左步骤 + 右运行详情**（对齐报告用例详情） |

**步骤规模假设**：绝大部分用例 ≤3 步，一般不超过 5 步。

## 1 整体布局

```
┌ 顶栏：用例名 · 运行环境 · 保存 · 调试 ─────────────────────────┐
├ 步骤 Tab 栏（横向 scroll）              [+添加▾] [粘贴步骤] ─┤
├ 辅助：右键页签可管理步骤（Typography.Text secondary）──────────┤
├ 下方内容区（flex:1，overflow:auto）────────────────────────────┤
│  · 普通步骤 → 步骤详情编辑                                        │
│  · If/For   → 分支块 + 子步骤 Collapse 列表                       │
├ 调试结果底部 Drawer（可收起）───────────────────────────────────┤
│  左 220px 步骤列表（✅/❌） │ 右 运行详情 Tab（CaseDebugDetail）    │
└───────────────────────────────────────────────────────────────┘
```

- **移除**：左右分栏拖拽条（`case-detail-step-splitter`）、步骤栏 Checkbox 全选/多选、底部「复制步骤」批量按钮。
- **保留**：顶栏环境/保存/调试；粘贴步骤在 Tab 栏最右侧。

## 2 步骤 Tab 栏

### 2.1 Tab 展示

| 规则 | 说明 |
|------|------|
| 文案 | `{序号}.` + `{类型 Tag}` + `{标题 ellipsis}` |
| Tag | 「自定义接口请求」→「接口请求」；「调用函数」purple，其余 blue/default |
| 溢出 | `overflow-x: auto`；选中 Tab **自动滚入视口** |
| 调试态 | Tab 前 ✅ / ❌（调试完成后） |
| If 链 | **整链占一格 Tab**（If + ElseIf + Else 合并，不按分支拆 Tab） |
| For | 一个控制器占一格 Tab |

### 2.2 右侧操作

| 控件 | 行为 |
|------|------|
| + 添加步骤 | Dropdown，类型与现 `CASE_STEP_TYPES` 一致 |
| 粘贴步骤 | 按剪贴板顺序追加根级步骤；无内容 disabled |

### 2.3 排序

- Tab **拖拽把手**调整根级顺序（If 链作为整体移动）。
- 右键 / ⋯ 菜单：**前移**、**后移**。

### 2.4 步骤菜单（右键 Tab 与 Tab 右侧 ⋯ 同内容）

| 菜单项 | 说明 |
|--------|------|
| 复制当前步骤 | 快照 **追加** 至剪贴板（非覆盖） |
| 复制到… | 沿用现弹窗 |
| 添加 | 子类型 Dropdown |
| 删除 | `Modal.confirm`，含「不可恢复」 |
| 前移 / 后移 | 根级排序 |

### 2.5 空态与提示

- 无步骤：`Empty` + 添加引导。
- 有步骤时一行：`Typography.Text type="secondary"` — **「右键页签可管理步骤」**。

## 3 If / For Tab 交互

| 操作 | 行为 |
|------|------|
| **右键 Tab** | 打开 **条件/循环配置**（Modal 或 Popover；If 条件编辑器、For 循环配置） |
| **左键 Tab** | 选中 + 下方进入 If/For 态；弹出 **控制项**：复制、删除、添加步骤（与现 If/For 块头部一致） |

---

## 4 下方内容区 — 两种态

### 4.1 态 A：普通步骤

选中普通 Tab → 下方展示完整步骤详情（与现右侧详情一致：标题、接口/函数/DB/等待等分区）。

### 4.2 态 B：If / For

- **不展示**控制器空详情页。
- **If 链**：上下排列 If 体 / ElseIf 体 / Else 体；每块含条件摘要、子步骤 Collapse、+ 添加子步骤。
- **For**：循环摘要 + 子步骤 Collapse + 添加区。
- **子步骤行**：序号 + Tag + 标题 + 展开箭头 + ⋯；展开区为完整步骤详情；**默认单开**（切换时收起其他）。

---

## 5 复制 / 粘贴

| 项 | 规则 |
|----|------|
| 删除 | Checkbox 多选 UI |
| 复制 | 菜单「复制当前步骤」→ 剪贴板 **append** |
| 多次复制 | 连续复制多步后，粘贴一次批量追加 |
| 跨用例 | 剪贴板跨 Tab 保留 |

## 6 单用例调试 — 底部抽屉

| 项 | 说明 |
|----|------|
| 容器 | `Drawer placement="bottom"`，`getContainer` 限定用例详情内容区 |
| 高度 | 默认 `min(480px, 50vh)` |
| 内部 | **grid 220px 1fr**：左步骤 List（✅/❌ + 高亮），右 `DebugStepDetailTabs` |
| 联动 | 点击 Tab / 抽屉左侧步骤双向同步 `activeStepId` |
| 收起 | 底沿展开把手；不遮挡 Tab 栏 |
| 对齐 | 与 `TestRunDetail` / `PlatformAutomationTaskDetail` 用例详情抽屉同结构 |

## 7 验收要点

1. 3～5 步 Tab 单行可见；Mock 10 步时横向滚动 + 选中滚入视口。
2. 普通步骤：选 Tab → 下方详情；右键/⋯ 可复制、删除、排序。
3. If/For：右键配置；左键下方分支 + 控制项；子步骤 Collapse 可编辑。
4. 连续「复制当前步骤」3 次再粘贴 → 追加 3 个根步骤。
5. 调试完成 Tab 与抽屉左侧均显示 ✅/❌；底部抽屉左右栏与报告一致。
6. 辅助提示「右键页签可管理步骤」可见。
