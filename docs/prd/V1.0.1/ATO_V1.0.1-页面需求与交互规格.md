## 2 数据流与状态机（页面 12）

### 2.1 数据获取时机

| 场景 | 时机 | API（Mock 占位） | 说明 |
|------|------|------------------|------|
| 任务列表查询 | 进入页面、切换 Tab、切换团队、搜索、点击“我创建的”、分页变化 | `GET /api/application/platform/tasks` | 入参含环境 Tab、团队、关键词、创建人过滤、分页 |
| 任务详情查询 | 点击任务名称进入详情页时 | `GET /api/application/platform/tasks/:taskId` | 返回基本信息、配置信息、运行统计、测试报告摘要 |
| 创建任务-步骤数据 | 打开创建向导 | `GET /api/application/platform/task-create-meta` | 返回团队、项目、版本、环境模板、模块、标签等选项 |
| 创建任务提交 | 第三步点击“提交” | `POST /api/application/platform/tasks` | 成功后返回列表并新增数据 |
| 删除任务 | 删除二次确认后 | `DELETE /api/application/platform/tasks/:taskId` | 成功后刷新当前列表 |

### 2.3 关键状态机

**A. 列表查询状态机**

`空闲 -> 查询中 -> 成功`  
`空闲 -> 查询中 -> 失败（错误提示 + 保留当前筛选条件）`

**B. 创建任务三步向导状态机**

`步骤1(任务信息) -> 下一步 -> 步骤2(环境变量确认) -> 下一步 -> 步骤3(用例运行配置确认) -> 提交中 -> 成功（关闭并刷新）`

失败分支：
- 步骤校验失败：停留当前步骤，定位错误项
- 提交失败：停留步骤3，保留输入，允许重试

## 3 页面详细设计

### 3.12 自动化应用 / 平台自动化

**页面信息**
- 路由：`/application/platform`
- 框架：主框架页面
- 入口：主菜单 `自动化应用 -> 平台自动化`
- 参数：无必传路由参数；查询参数可选（用于保留筛选状态）

**页面目标**
- 按环境与团队维度管理平台自动化测试任务，完成任务查询、创建、删除、查看等核心动作。

### 3.12.1 布局与区块

- 整体布局：单栏列表页（不使用左右分栏）。
- 顶部第一层：环境 Tab
  - `测试环境`
  - `开发环境`
- 顶部第二层：工具条
  - 左侧：`创建测试任务` 主按钮
  - 右侧（从左到右）：
    1. 团队下拉过滤（位于搜索框前，默认值=`全部团队`）
    2. 任务搜索框（占位：`请输入任务名称`）
    3. `我创建的` 快捷过滤按钮（开关态）
- 主体：任务表格
- 底部：分页器 + 每页条数选择 + 总数显示

### 3.12.2 环境 Tab 规则

- 两个 Tab 功能完全一致（同字段、同操作、同交互）。
- 通过 Tab 执行环境数据与权限隔离：
  - 仅返回当前 Tab 对应环境下的任务数据；
  - 用户角色决定当前 Tab 是否具备编辑权限（角色来源：基础数据中的用户角色字段）：
    - 角色=`测试`：`测试环境`可编辑，`开发环境`仅查看
    - 角色=`开发`：`开发环境`可编辑，`测试环境`仅查看
  - 仅查看权限下，页面可浏览数据但禁用创建/编辑/删除等写操作（按钮禁用并给出提示）。

### 3.12.3 表格字段定义

按顺序展示：
1. 任务ID
2. 任务名称（可点击）
3. 版本
4. 创建时间（`YYYY-MM-DD HH:mm:ss`）
5. 触发时间（`YYYY-MM-DD HH:mm:ss`）
6. 耗时（未完成显示 `-`）
7. 触发方式
8. 用例数
9. 通过率
10. 进度
11. 运行状态（圆点 + 文案）
12. 操作（编辑 / 运行或停止 / 删除）

- 统计口径约束：通过率与进度的计算口径与现有“测试运行”模块保持完全一致。

### 3.12.4 创建/编辑任务（三步向导）

**入口**
- 点击 `创建测试任务` 打开向导页（非单弹窗）。
- 点击表格行 `编辑` 按钮打开同一向导页（编辑模式）。

**步骤流转**
1. 任务信息
2. 环境变量确认
3. 用例运行配置确认
4. 点击提交后创建成功

**公共按钮**
- `取消`：返回任务列表，未提交不落库
- `上一步`：第一步禁用
- `下一步`：校验通过后进入下一步
- `提交`：仅步骤3显示

**步骤1：任务信息**
- 基础信息区：任务名称*、所属团队*、所属项目*、用例版本*（两行两列均匀布局）
- 触发方式*：手动触发 / 定时触发 / 周期触发
  - 定时触发：显示“触发时间”（年月日时分秒）
  - 周期触发：先选触发周期（每天/每周）；每天=选时间；每周=先选星期再选时间
- 发送邮件*（总是发送 / 成功后发送 / 不发送）
- 发件人
- 收件人（支持姓名/邮箱模糊搜索、多选）
- 团队选择（单选）：选择后自动填充团队成员邮箱；支持清空重置

**步骤2：环境变量确认**
- 环境模板下拉：选项来源于“所选项目 + 用例版本”对应环境列表
- 应用服务器配置（可编辑）：服务名/协议/IP(域名)/端口
- 配置 Tab：自定义环境变量 / Headers / 设备配置 / 中间件配置
  - 自定义环境变量 / Headers：仅允许改“变量值（参数值）”，不允许新增变量名
  - 设备配置：与页面 6「变量管理」设备配置交互一致（添加、搜索、编辑、删除）
  - 中间件配置：与页面 6 一致，按 Mysql / Clickhouse / Kafka 子 Tab 展示固定配置项，仅改配置值

**步骤3：用例运行配置确认**
- 执行范围（独立卡片）
  - 所属模块*：关系（包含/不包含）+ 树形多选模块；默认“包含 + 所有用例（不预填模块）”
  - 标签：多行条件（等于/包含/不包含 + 标签选择），支持行内新增/删除
- 并行配置（独立卡片）
  - 分组：按一级模块分组 / 自定义模块分组 / 按分组标签分组（默认按分组标签分组）
- 失败重试次数（默认 0）
- 单用例最大执行超时时长（秒，默认 600）
- 运行完成后清理目录（复选框）

**提交反馈**
- 成功：提示“创建任务成功”，关闭向导并刷新当前 Tab 列表
- 失败：提示“创建任务失败”，停留步骤3并保留数据

**编辑模式约束（本迭代）**
- 第一步 `任务信息`：允许修改 `任务名称`、`触发方式`、`发送邮件`；所属团队/所属项目/用例版本保持只读
- 第二步 `环境变量确认`：允许编辑环境与配置值
- 第三步 `用例运行配置确认`：只读，不允许修改
- 编辑提交成功提示：`更新成功`；失败提示：`更新失败`

### 3.12.5 关键交互

1. **团队筛选**
   - 在右上团队下拉选择团队，刷新当前 Tab 列表
2. **任务搜索**
   - 输入关键字回车后按任务名称过滤，页码重置为第 1 页
3. **我创建的**
   - 点击后仅展示创建人=当前用户的任务，再次点击取消
4. **查看任务**
   - 点击任务名称（主入口）进入任务详情页
5. **编辑任务**
   - 点击编辑按钮进入三步向导（编辑模式）
   - 第一步允许改任务名称/触发方式/发送邮件；第二步可编辑；第三步只读
6. **删除任务**
   - 二次确认文案固定为：`此操作不可恢复，是否继续？`
   - 成功后从列表移除并提示成功
7. **运行/停止任务**
   - 操作列根据当前状态显示“运行”或“停止”图标，点击后切换任务状态并提示结果

### 3.12.6 任务详情页（平台自动化）

**页面信息**
- 路由：`/application/platform/tasks/:taskId`
- 入口：平台自动化列表点击任务名称（主入口）
- 返回：点击左上返回按钮返回列表，并保留原筛选条件（环境 Tab、团队、搜索关键词、“我创建的”）

**页面结构（按评审截图）**
- 顶部：返回按钮 + 标题 `测试任务：{taskId}`
- 顶部 Tab：`任务详情`、`测试报告`
- `任务详情` Tab：按区块展示
  1. 基本信息
  2. 配置信息
  3. 运行统计
- `测试报告` Tab：与 V1.0.0「测试运行 -> 任务详情」中的测试报告形态保持一致
  1. 左侧运行记录区（默认折叠，可展开）
  2. 中间折叠控制条（控制左侧运行记录区）
  3. 右侧上方运行汇总区（默认折叠，可展开）
  4. 右侧下方测试报告主体（目录树 + 状态筛选 + 用例列表）

**测试报告 Tab 结构（与 V1.0.0 对齐）**
- 左侧运行记录：
  - 按时间倒序展示历史运行记录（如 `#5`、`#4`...）
  - 点击运行记录切换右侧汇总与报告数据
- 右侧汇总区（可折叠）：
  - 成功/失败/异常/跳过统计
  - 覆盖率、总耗时、平均请求耗时、测试环境、接口总数、按口执行数
- 右侧报告主体：
  - 左侧目录树：仅展示模块层级，附状态计数
  - 右侧状态筛选：全部/成功/失败/异常/跳过
  - 用例列表列：用例ID、用例名称、标签、所属模块、运行结果、关联Bug Id
  - 点击用例名称：右侧抽屉展示用例运行详情（步骤内请求/响应/断言等可折叠）
  - 用例ID仅展示，不提供跳转

**任务详情 Tab 字段建议**
- 基本信息：任务ID、版本、所属项目、任务状态、创建时间、触发方式、发送邮件策略
- 配置信息：运行环境、并行线程数、重试配置、执行耗时、执行范围（模块/标签）
- 运行统计：用例总数、运行用例数、总运行次数、最近运行统计（覆盖率/通过率/耗时）、平均运行统计

**交互约束**
- 页面加载失败时可重试
- Tab 切换不丢失已加载数据
- 字段为空显示 `-`
- `测试报告` Tab 中目录树筛选与状态筛选需联动过滤用例列表

### 3.12.7 状态与异常

- 加载态：表格 `loading`，按钮禁用防重复操作
- 空态：`Empty` + 引导按钮“创建测试任务”
- 无权限态：显示无权限提示，不展示可操作数据
- 错误态：查询失败可重试；提交失败保留表单输入
